# Changelog

## RPS-1 v0.1 (Working Draft), 2026-10-19

First public draft, prepared by the founders of the RoboIns Association for public comment.

- System classes 1–3 and fleet risk.
- Core Parameter Matrix with eight parameters; provisional scales for AUT, ENV, OVS and LOG.
- Draft trigger library (T-A1 to T-A4, T-R1 to T-R3, T-X1 to T-X4, T-F1) with admission criteria.
- Oracle and evidence requirements.
- Agent Incident Record and JSON schema v0.1.
- Certification levels RPS Ready, RPS Verified, RPS Insured (procedure not yet defined).
- Open questions for consultation.
