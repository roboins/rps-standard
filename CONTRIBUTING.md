# Contributing

RPS-1 v0.1 is an early draft and we welcome comments from insurers, operators, manufacturers, researchers, regulators and anyone affected by autonomous systems.

- **Comments and questions:** open an issue. Please name the section (for example "Section 6.2, T-A4") and, if you can, propose wording.
- **Changes to text or schema:** pull requests are welcome; please open an issue first for larger changes.
- **Private feedback:** write to info@roboins.org.

By submitting a contribution you agree that it may be published under the licenses of this repository (CC BY 4.0 for text, Apache 2.0 for schema and examples).

Decisions on the draft are taken by the founders until the technical council is formed. From version 1.0, each version is intended to go through at least 60 days of public consultation.
